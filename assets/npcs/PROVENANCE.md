# Named-NPC figures

Reserved for a specific hero/NPC rather than the generic class or troop
rosters (figures3d.gd's HERO_MODELS/FOE_MODELS are keyed by class/faction,
not by individual character — this directory is for the exception).

## female_mage.glb
Source: Meshy Community feed, downloaded by the user directly ("Meshy AI
Beautiful female mage_0912194205_texture.glb"). License: CC0 1.0 (Meshy
ToS §3.3). Static mesh, no rig/animation — not run through
run_community_rig.py since there's no specific character or combat use
picked for it yet. Not wired into any registry. Rig it (remesh -> rig ->
Idle, same chain as orc_heavy) once it's actually assigned to a named
character who'll stand in combat.
