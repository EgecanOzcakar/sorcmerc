Generated by `tools/audit_levels.py`. Expectations are dnd-maintainer's
structural table, which proves a level is *shaped* right, never that it
matches the book. An empty level, though, is empty for certain.

- **Rogue** — last grant at level 10
- **Fighter** — last grant at level 16
