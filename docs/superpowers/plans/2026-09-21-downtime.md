# Downtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Five things a company does in town that take days — training a feat, carousing, gambling, crafting at the counters, the city's pit bracket — each a row on a page the game already has, each spending world-days the clocks eat, each able to turn into a small story.

**Architecture:** One static module, `core/downtime.gd` (`Downtime`), in `settlement_visit.gd`'s row shape (`{ok, nat, bonus, dc, text, ...}` seeded off the visit), with state on `party.downtime` (saved). The world screen adds a Downtime section to the inn page and Brew/Scribe rows at two counters; complications are event cards; the pit's bouts are ordinary encounters with a one-foe roster and a named champion.

**Tech Stack:** Godot 4.7 / GDScript; headless `SceneTree` tests; ComfyUI for nine scenes.

**Spec:** `docs/superpowers/specs/2026-09-21-downtime-design.md`

## Global Constraints

- Every godot invocation is `--headless`; screen tests `SORCMERC_FAST=1 timeout 180`.
- `core/downtime.gd` preloads `campaign.gd`, `settlement_visit.gd`, `faction_opinion.gd`, `ladder.gd`, `rumors.gd`, `rng.gd`, `dice.gd`, `achievements.gd`, `rules/catalog.gd`, `enemy_names.gd`; it must not be preloaded by any of those (the screen preloads it).
- Constants verbatim: `DAY 1440.0`; `TRAIN_COST_BASE 150`, `TRAIN_COST_PER_LEVEL 50`, `TRAIN_DAYS 5`, `TRAIN_MIN_LEVEL 4`, `TRAIN_CATEGORY "general"`; `CAROUSE_COST {"city": 30, "town": 20, "camp": 10}`, `CAROUSE_DC 13`, `CAROUSE_CONTACT 5.0`, `CAROUSE_COIN 15`, `CAROUSE_SKILLS ["persuasion", "performance"]`; `GAMBLE_DC 12`, `GAMBLE_STAKES [25, 50, 100, 200]`, `GAMBLE_SKILLS ["insight", "deception", "sleightofhand"]`, payouts nat 20 ×3 / ≥ DC+5 ×2 / ≥ DC ×1.5 / < DC lose / nat 1 lose + insult; `CRAFT_RATE 0.5`, `CRAFT_DAYS 1`; `PIT_PURSE [60, 120, 240]`, `PIT_MULT [1.3, 1.7, 2.2]`, `PIT_WEEK 7 × DAY`, `PIT_BOUTS 3`; complications `["tab", "brawl", "insult", "bad_lead"]`, `TAB_MULT 2`, `INSULT 5.0`.

### Task 1: `core/downtime.gd` — the activities, pure

**Files:** create `core/downtime.gd`, `tests/test_downtime.gd`; modify `core/party.gd` (`var downtime: Dictionary = {}`), `core/world_save.gd` + `core/campaign_save.gd` (`"downtime"` beside `callings`), `core/rumors.gd` (a `dud` lead: `static func dud(settlement) -> Dictionary` returning `{"ok": true, "price": 0, "text": "…", "dud": true}` — a rumour that names nothing), `core/achievements.gd` (four entries: `trained_first` *Schooled* counter `trained` 1; `carouse_contact` *Friends in Low Places* counter `contacts` 1; `gamble_treble` *The House Loses* counter `trebles` 1; `pit_champion` *Champion of the Pit* counter `pit_brackets` 1).

**Produces:**

```gdscript
static func spend_days(party, world, s, days: int) -> int        # clock += days*DAY; Visit.rest(party, world, "long-rest") once; pays inn_cost(s) × days (spend_gold; returns the gold paid, -1 if the purse could not); Ach.bump("downtime_days", days)
static func can_train(party, ch) -> bool                          # level >= TRAIN_MIN_LEVEL and ch.id not in party.downtime.trained
static func train_cost(ch) -> int
static func trainable(ch) -> Array                                # general-category feat ids the sheet lacks (ch.feats and its expanded bundles — read core/rules/bundles.gd expanded_feats)
static func train(party, world, s, ch, feat_id: String) -> Dictionary   # pays, spends TRAIN_DAYS, appends to ch.feats, ch.dirty(), records; {"ok", "text", "feat_name", "days", "cost"} or {} refused
static func carouse(party, world, s, rng = null) -> Dictionary    # pays CAROUSE_COST[kind]; one day; roll; {"ok","nat","bonus","dc","text","contact":bool,"lead":Dictionary,"coin":int,"complication":String}
static func can_gamble(party, s) -> bool                          # once per visit: party.downtime.gambled_at[s.id] != s.last_visited
static func gamble(party, s, stake: int, rng = null) -> Dictionary    # {"ok","nat","bonus","dc","mult":float,"won":int,"text","complication"}
static func brewable(s, m: Dictionary) -> Array                   # alchemist's potion ids on the visit's shelf; scribable(s, m, party) -> Array (SCROLL_IDS if a caster)
static func craft(party, world, s, item_id: String, m: Dictionary) -> Dictionary  # half price, one day, stash identified, once per item per visit (party.downtime.crafted[s.id][item] == last_visited)
static func pit_bracket(s, world) -> Dictionary                   # {"week", "names": [3], "monster": id, "levels": [+1,+2,+3]} seeded off (s.id, week); names via EnemyNames.name_for(s.faction, "pit|%s|%d|%d")
static func pit_state(party, s, world) -> Dictionary              # {"week", "beaten", "open": bool}
static func pit_spec(party, s, world, bout: int, base_spec: Dictionary) -> Dictionary   # the strongest humanoid entry of base_spec["monsters"] kept, count 1, mult PIT_MULT[bout], spec["named"] = {id: name}, theme "city-square"
static func pit_result(party, s, world, bout: int, won: bool) -> Dictionary   # won: purse PIT_PURSE[bout], Ladder.deed(s.faction), beaten += 1, third → Ach.bump("pit_brackets"); lost: gold -PIT_PURSE[bout] (to zero), bracket closed (beaten = -1 for the week); {"text", "purse"}
static func complication(kind: String, s, cost: int) -> Dictionary    # {"id": "downtime-<kind>", "title", "kind": "bad", "text", "gold": -n | "opinion": -5 | "fight": true | "lead": dud}
static func to_dict(party) / from_dict(party, d)
```
