# The Lodge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One house bought once in a town where the company is Known, with five rooms built onto it — a strongroom the road cannot take from, a training yard for retraining, an herb garden and a map room that accrue while away, a shrine — each a gold sink with a visible answer on the map and a use on the road.

**Architecture:** `core/lodge.gd` (static; state on `party.lodge`, saved); the town square's button and a lodge visit page on the world screen; `_retreat` spares stored gold; a lodge diorama beside its town built by `settlement_kit.gd` that gains a part per room; the yard's retraining goes through `Downtime.spend_days` and the trainer's own ability decision.

**Tech Stack:** Godot 4.7 / GDScript; headless `SceneTree` tests; ComfyUI for six scenes.

**Spec:** `docs/superpowers/specs/2026-09-21-lodge-design.md`

## Global Constraints

- Every godot invocation is `--headless`; screen tests `SORCMERC_FAST=1 timeout 180`.
- `core/lodge.gd` preloads `ladder.gd`, `downtime.gd`, `rumors.gd`, `faction_opinion.gd`, `achievements.gd`, `campaign.gd`, `rules/catalog.gd`; none of them preloads it.
- Constants verbatim: `HOUSE_COST 400`; rooms `strongroom 200`, `yard 300`, `garden 150`, `shrine 200`, `maproom 250` (titles "the strongroom", "the training yard", "the herb garden", "the shrine", "the map room"); `RETRAIN_COST 100`, `RETRAIN_DAYS 3`; `GARDEN_DAYS 3`, `GARDEN_CAP 3`, `GARDEN_ITEM "potion-of-healing"`; `MAPROOM_DAYS 4`, `MAPROOM_CAP 2`; `DEPOSIT_STEPS [50, 100, 200]` plus "all".
- Buying needs: no lodge; a civilized settlement; `Ladder.rung(s.faction) >= Ladder.KNOWN`; the gold. One lodge ever. Rooms build at once.
- Copy verbatim: buy button *"Buy a lodge here (400 ◉)"*, page button *"Your lodge"*, elsewhere line *"The company's lodge is at %s."*, buy line *"The deed is signed. The company has a door of its own in %s."*, garden line *"The garden has %d potion(s) ready."*, map room line *"The map room has %d lead(s) pinned."*, shrine leave line *"The shrine's blessing goes with them."*, label suffix *" · your lodge"*.
- Commit after every task, repo voice, trailer `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`; `.uid` tracked.

### Task 1: `core/lodge.gd`, the state, the save

**Files:** create `core/lodge.gd`, `tests/test_lodge.gd`; modify `core/party.gd` (`var lodge: Dictionary = {}`), `core/world_save.gd` + `core/campaign_save.gd` (`"lodge"` beside `downtime`), `core/achievements.gd` (`lodge_bought` *A Door of Our Own* counter `lodges` 1; `lodge_full` *Every Room Built* counter `lodge_rooms` 5 — both `Ach.record`ed), `core/downtime.gd` (expose the ability decision as `Downtime.decide_ability(ch, feat_id)` if it is private — the yard reuses it).

**Produces** (the spec §1 signatures, plus): `Lodge.rooms_built(party) -> int`; `Lodge.settlement(party, world)` → the Settlement or null; `Lodge.stored(party) -> int`; `Lodge.spare_from_loss(party, lost: int) -> int` (the strongroom's gold is never part of a loss — the screen's `_retreat` computes the loss from `party.gold` only, so this is just a documented no-op guard; keep `deposit`/`withdraw` moving gold between `party.gold` and `party.lodge.gold`); `Lodge.collect(party, world)` accrues from `garden_at`/`maproom_at` to `now` in whole periods, caps, stashes the potions identified and takes the leads through `Rumors.free_lead(s, party, world)` (each lead marks its target; stop when it returns `{}`), re-stamps to `now`, returns `{"potions", "leads", "text"}`; `Lodge.retrain(party, world, ch, old_feat, new_feat)`: `old_feat` must be in `ch.feats` and general, `new_feat` in `Downtime.trainable(ch)`; removes old (and its decided ability choice — read how `ch.choices` keys the feat's `ability-choice` and erase it; `ch.dirty()`), appends new, decides its +1 (`Downtime.decide_ability`), charges `RETRAIN_COST`, `Downtime.spend_days(party, world, s, RETRAIN_DAYS)` where `s` is the lodge's settlement, once per hero per visit (`party.lodge.retrained` cleared when the visit's `last_visited` changes — simplest: store `{char_id: s.last_visited}`); `Lodge.bless(party)` sets `party.blessed = true` once per visit (`blessed_at == last_visited` guard).

Tests per spec §4 (build a world with a human city Riverhold at the origin; `Ladder.reset()`, `Ladder.deed("human", 4)` to be Known; `Party.demo_roster()`; `FactionOpinion.reset()`; `Ach._current = Ach.new()`).
